# 🏕️ Guide du Système de Progression - Paradis du Camping

## 🎮 Vue d'ensemble

Le jeu est maintenant centré sur la **progression de votre camping** à travers les mini-jeux et l'amélioration d'objets qui génèrent du revenu passif.

## 📖 Comment jouer

### 1. 🎯 Jouer aux Mini-Jeux

Participez aux différents mini-jeux pour gagner de l'argent et débloquer des achievements :

- **🎣 Pêche** : Attrapez des poissons (communs, rares, légendaires)
  - Achievement : **Poisson Rare** (1 poisson rare attrapé)
  - Achievement : **Poisson Légendaire** (1 poisson légendaire attrapé)

- **🪓 Coupe de Bois** : Coupez des arbres pour collecter des bûches
  - Achievement : **Maître Bûcheron** (50 bûches coupées)

- **🧩 Labyrinthe** : Complétez le labyrinthe
  - Achievement : **Explorateur** (1 labyrinthe complété)

- **🏌️ Golf Kart** : Conduisez le kart de golf
  - Contrôles PC : WASD + Shift pour changer de vitesse
  - Contrôles Mobile : Boutons tactiles sur l'écran

### 2. 💰 Améliorer votre Camping

Ouvrez le menu "🏕️ Camping" (bouton sur le côté droit) pour :
- Voir tous les objets disponibles
- Acheter et améliorer vos équipements de camping
- Chaque objet a plusieurs niveaux (1, 2, 3, 4...)

### 3. 📦 Objets de Camping

#### 🚐 Roulottes (Trailer)
- **Niveau 1** : +5$/tick - Gratuit (objet de départ)
- **Niveau 2** : +15$/tick - 500$ + Poisson Rare
- **Niveau 3** : +40$/tick - 2000$ + Poisson Légendaire + Explorateur
- **Niveau 4** : +100$/tick - 5000$ + Tous les achievements

#### 🍖 BBQ
- **Niveau 1** : +2$/tick - 200$
- **Niveau 2** : +6$/tick - 800$ + Explorateur
- **Niveau 3** : +15$/tick - 3000$ + Poisson Rare + Maître Bûcheron

#### 🪑 Table de Pique-nique
- **Niveau 1** : +1$/tick - 150$
- **Niveau 2** : +3$/tick - 600$
- **Niveau 3** : +8$/tick - 2500$ + Poisson Rare

#### 🔥 Feu de Camp
- **Niveau 1** : +3$/tick - 300$
- **Niveau 2** : +8$/tick - 1200$ + Maître Bûcheron
- **Niveau 3** : +20$/tick - 4000$ + Tous les achievements

#### 🌲 Arbres Décoratifs
- **Niveau 1** : +1$/tick - 100$
- **Niveau 2** : +3$/tick - 400$
- **Niveau 3** : +7$/tick - 1500$

#### 🪨 Rochers Décoratifs
- **Niveau 1** : +0.5$/tick - 50$
- **Niveau 2** : +2$/tick - 300$

### 4. 💸 Revenu Passif

Une fois acheté, chaque objet génère automatiquement de l'argent toutes les 5 secondes !
- Exemple : Si vous avez Trailer_2 (+15$/tick) et BBQ_1 (+2$/tick), vous gagnez 17$ toutes les 5 secondes

### 5. 🏆 Débloquer des Achievements

Les achievements se débloquent automatiquement en jouant :
- **CaughtRareFish** : Attrapez 1 poisson rare
- **CaughtLegendaryFish** : Attrapez 1 poisson légendaire
- **CompletedMaze** : Complétez 1 labyrinthe
- **WoodMaster** : Coupez 50 bûches
- **CompletedSwingLoops** : Faites des loopings sur la balançoire

## 🎯 Stratégie de Progression

1. **Début** : Jouez aux mini-jeux pour accumuler de l'argent
2. **Phase 1** : Achetez BBQ_1, PicnicTable_1, TreesDecor_1 (pas de prérequis)
3. **Phase 2** : Débloquez les achievements en jouant
4. **Phase 3** : Améliorez vos objets pour augmenter le revenu passif
5. **Objectif Final** : Obtenez tous les objets au niveau maximum !

## 🌳 Décoration du Terrain

Le bouton "🎨 Décorer le terrain" permet de placer des éléments décoratifs supplémentaires (arbres, roches) sur votre parcelle, en dehors des objets de camping.

## 📊 Suivi de Progression

- Vos stats sont suivies automatiquement (poissons pêchés, bûches coupées, etc.)
- Les achievements se débloquent automatiquement quand vous atteignez les objectifs
- Votre revenu passif augmente avec chaque amélioration
